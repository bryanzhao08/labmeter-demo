Ask the instrument manager to locate the software’s usage or acquisition log. Select that folder, or its approved server copy. LaBro reads selected text logs only; it does not move experimental data or change the instrument.

2. Describe the log

CSV, TSV and delimited text with a header row are supported. Proprietary or free-form manufacturer logs need a separate adapter based on a real sample.

Use the instrument’s configured time convention. Local timestamps cannot distinguish a repeated daylight-saving hour; resolve those records against the source log before billing.
