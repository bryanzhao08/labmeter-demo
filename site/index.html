How the agent works

01

Find

Detects which booking system the core uses: FBS, iLab, PPMS.

02

Collect

Pulls the month's reservations, usage logs and price sheet from a connected folder or the iLab API.

03

Match

Lines up every booking with logged instrument time.

04

Price

Applies the core's own rules: tiers, after-hours, rounding.

05

Review

Flags no-shows, overruns and odd sessions; the manager approves; nothing is billed without a person.

Runs on your computer. Files never leave it.

Works with the exports you already have.

Any MCP agent can drive it: Claude, Copilot Studio, n8n.

What it connects to

FBS · iLab · PPMS · Booked Scheduler · Excel/CSV

FBS has no public API, so LaBro reads FBS's exports. iLab connects with an API token.
