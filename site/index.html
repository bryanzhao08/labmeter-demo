How it works

Finder

Detects the lab's booking system and data sources.

Collector

Pulls the month's bookings, instrument logs and price sheet.

Matcher

Pairs every booking with the time the instrument actually ran.

Pricer

Applies the lab's own rates, tiers and after-hours rules.

Reviewer

Flags no-shows, overruns and outliers, then hands you one bill to approve.

Every agent's work is checked by deterministic rules before it reaches you.

Under the hood

Multi-agent orchestration
Specialist agents for discovery, collection, reconciliation, pricing and review, coordinated by a planner.
Model Context Protocol server
Any MCP-capable agent can call LaBro's tools: find exports, read prices, check a month.
Interval reconciliation engine
Merges booked and logged intervals per user, instrument and day, with per-machine billing policies.
Rate-sheet parser
Reads price sheets in Excel, CSV or plain text into tiers, after-hours windows and rounding rules.
Anomaly scoring
Statistical outlier detection on session length and charge within each machine and month.
Local-first runtime
Electron desktop app; data stays on the lab's machine. API tokens are encrypted in the OS keychain.
Human-in-the-loop
Nothing is billed until a manager approves; every charge carries its evidence.

FAQ

Why does a lab need agents for this?

Each month someone has to find the exports, match thousands of bookings against instrument logs, apply rules that differ by machine, and chase exceptions. That is a chain of judgment calls across several systems: the kind of work agents do well, with a person approving the result.

Does LaBro replace our booking or billing system?

No. It works alongside FBS, iLab, PPMS and the rest, and hands back a reviewed bill in the format you already upload.

Where does our data go?

It stays on your computer. LaBro runs locally and only talks to the systems you connect.

What if an agent gets something wrong?

Every charge shows the booking and log it came from, and nothing is billed until you approve it.

How long does setup take?

About ten minutes: connect your exports folder or system, check the price sheet LaBro reads, and run a month.

Which instruments does it work with?

Any instrument with a booking and a usage log: flow cytometers, microscopes, NMR, mass spectrometers, sequencers.

Can our own AI assistant use it?

Yes. LaBro exposes its tools over MCP, so Claude, Copilot Studio or n8n can run checks.
